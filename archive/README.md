  `ttt_gen_diag2.py`, `ttt_lift_test.py`
- llama.cpp LoRA-bridge gates (Stage 2): `ttt_gate1.py`, `ttt_gate2.py`, `ttt_gate3.py`,
  `test_convert_subprocess.py`
- Superseded PowerShell orchestrators (replaced by python ones that survive laptop disconnect):

  `rig_archive.ps1`
